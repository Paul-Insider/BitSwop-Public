# Security policy

## Scope

This is an offline Rust showcase, not a production payment system. Findings in
this repository do not establish the behavior of the private BitSwop product.

## Reporting

Use GitHub private vulnerability reporting if that feature is enabled for this
repository. Otherwise use the private contact options published on
[bitswop.com](https://bitswop.com) to request a suitable reporting channel.

Do not open a public issue containing secrets, customer data or exploit details
for a live service. Include only the affected sample version, a minimal
synthetic reproduction and expected versus observed behavior in a private report.

No bug-bounty reward, response time or security audit is implied.
