# Repository terms

## Purpose

This repository provides one limited Rust illustration for inspection and
private technical evaluation. It is not the complete BitSwop implementation,
a supported SDK, a production integration guide or an offer of financial services.

## Technical limits

The arithmetic module does not know a currency, token contract, network,
transaction identity or finality threshold. Its values cannot independently
establish that a customer has paid. Demonstration outputs use synthetic inputs.

Do not submit wallet keys, seed phrases, credentials, customer information or
transaction records to issues, pull requests or discussions. Local examples do
not need any of these materials.
